Walk all pattern matches.

The pattern is split into path prefix and actual glob, for example, "some/path/*/*.txt" is split into path "some/path" and glob "*/*.txt", the syntax rules apply only to the glob part.

The iterator sorts by file name, using the system sorting function. See FileNameSortKey for more details.

§Syntax

Standard Unix-style glob syntax is supported (provided by globset crate):

  • ? matches any single character.
  • * matches zero or more characters.
  • ** recursively matches directories but are only legal in three situations. First, if the glob starts with **/, then it matches all directories. For example, **/foo matches foo and bar/foo but not foo/bar. Secondly, if the glob ends with /**, then it matches all sub-entries. For example, foo/** matches foo/a and foo/a/b, but not foo. Thirdly, if the glob contains /**/ anywhere within the pattern, then it matches zero or more directories. Using ** anywhere else is illegal (Note that the glob ** is allowed and means “match everything”).
  • {a,b} matches a or b where a and b are arbitrary glob patterns or empty. (Note that nesting {...} is allowed.)
  • [ab] matches a or b where a and b are characters. Use [!ab] to match any character except for a and b.
  • [[:alpha:]], [[:digit:]], [[:space:]] etc. match POSIX character classes using ASCII-only definitions. Supported classes: alnum, alpha, blank, cntrl, digit, graph, lower, print, punct, space, upper, xdigit. These can be combined with regular ranges, e.g., [[:digit:]a-f] matches hexadecimal digits.
  • Metacharacters such as * and ? can be escaped with character class notation. e.g., [*] matches *. Backslash does not escape, it matches path separators on all platforms.
  • / and \\ matches path separators.

§Performance

A walkdir iterator is configured to iterator over only the file depths that might match and each file is checked against the compiled pattern, this is generally pretty fast, but note that if ** is in the pattern the entire directory depth is searched.

§Configuration

Use glob_build to modify the walkdir::WalkDir and globset::GlobBuilder before iteration starts.
