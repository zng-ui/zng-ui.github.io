Finish wizard operation.

This command represents the transition out of the wizard from the results page or the last config page.

If the wizard operation uses BEGIN_CMD the progress page will auto swap to a results page, the results page offers the FINISH_CMD, to perhaps close the wizard window.

The wizard operation can also simply represents a configuration that is instantly applied, in this case the last config page can directly call FINISH_CMD to exit the wizard.

The finish_cmd_name can be used to change the command display name.
